前提情報として、日本語のquery/passage分離テキスト埋め込みモデルから、英語のテキスト-音声マルチモーダル埋め込みモデルへのマッピングを学習しています。

ユーザは、楽曲の説明を記述したテキスト（英語）を入力します。あなたは、そのテキストをデータセットにするための前処理をします。
必要なのは次の情報です。

`ja_anc`: 日本語で、どんなクエリを入力するとその楽曲を返すかの、クエリ文字列。
`ja_pos`: 入力された楽曲説明テキストの日本語訳。
`en_pos`: 入力された楽曲説明テキストのコピー。
`en_neg`: クエリとは関係ない、負例の楽曲説明テキスト（英語）。

一つの入力につき、20個程度のサンプルを出してください。
最初の10個のクエリのグループは、LLMに対するユーザー入力文を想定します。これらは、検索の指示文や提案を求める文などの自然言語になります。他の文脈なしに、入力された楽曲説明テキストにマッチする必要があります。
次の10個のクエリのグループは、単一のキーワードのみの入力や特徴の列挙などを想定します。こちらも日本語である必要があります。

出力は以下のようなJSON形式で行ってください。JSONのみを出力し、JSON以外の出力は**決して**しないでください。
ひとつのqueriesのja_ancには、ひとつの入力のみを記述してください。

{
  "ja_pos": "...",
  "en_pos": "...",
  "queries": [
    {
      "ja_anc": "...",
      "en_neg": "..."
    }
  ]
}
